# Smart Mphunzitsi – Backend

AI-powered personal tutor backend for Malawi secondary education (Forms 1–4). Built with Node.js, Express, MongoDB, Youtube Data v3 for video links and integrated with Groq AI for chat and quiz generation.

## Features

- User authentication (JWT) with password reset via email
- Lesson management (CRUD) with form‑ and subject‑based filtering
- Progress tracking (completed lessons, scores, overall mastery)
- AI chat assistant (context‑aware, learning style adaptation)
- AI quiz generation (5 multiple‑choice questions per lesson)
- Role‑based access (public routes for lessons, protected for user data)
- Email notifications (nodemailer with Gmail SMTP)
- Security: rate limiting, input validation, helmet, CORS
